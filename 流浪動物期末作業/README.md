## 🌟 核心特色與改版重點 (V5 140題題庫與典範殿堂首頁)

1. **首頁「典範殿堂徽章式」大器排版 (方案 A)**
   - 放大並置中「🏛️ 國立臺灣大學獸醫專業學院 ✕ 國立臺灣科學教育館」典範大徽章。
   - 放大並置中「十五年的約定」主標題與「🐾 飼主責任特展 • 生命教育承諾」副標膠囊。
   - 移除原中央表情行，版面更開闊莊嚴，保有「想養只是一時喜歡，準備好是一生的承諾」漸顯金句。

2. **140 題全物種專業臨床題庫與隨機抽題**
   - 狗狗、貓咪、兔子、倉鼠四大物種各擴增至 35 題（共計 140 題）。
   - 每次開始遊戲透過 **Fisher-Yates 洗牌演算法** 隨機抽取 7 關考驗，兼具教育深度與重複遊玩性。

3. **守護愛心生命條（❤️❤️❤️）與階梯評級**
   - 初始擁有 3 顆愛心。答錯扣心時觸發心碎動態（`💔`）。
   - 0 錯為 S 級，錯 1 題為 A 級，錯 2 題為 B 級，錯 3 題生命耗盡觸發 F 級不及格飼主警告。

4. **Web Audio API 純合成音效與實體證書 PNG 下載**
   - 答對有金鈴聲，答錯有逼真動物哀鳴，首頁彩蛋點擊有歡樂叫聲。
   - 100% 離線純 HTML5 Canvas 繪製高解析度結業證書並一鍵儲存 PNG。
